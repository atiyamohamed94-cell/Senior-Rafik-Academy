# Senior Rafik Academy — نسخة مجانية أولية

واجهة عربية RTL لأكاديمية تعليم اللغة الإيطالية، مبنية بـ HTML وCSS وJavaScript عاديين، من غير اشتراكات أو مكتبات تحتاج تثبيت.

## تشغيلها
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح.
3. استخدم القائمة الجانبية للتنقل، وبدّل بين عرض المدرس وعرض الطالب من القائمة أعلى الشريط الجانبي.

## الموجود حاليًا
- واجهة لوحة مدرس وواجهة طالب تجريبية.
- إدارة بيانات طلاب تجريبية (إضافة، تعديل، حذف).
- إدارة الدروس والواجبات والإعلانات.
- إنشاء اختبار تفاعلي بسيط وتصحيح تلقائي.
- ملخص للدرجات والنقاط.
- حفظ البيانات في `localStorage` على نفس المتصفح والجهاز.

## مهم جدًا قبل استخدامه مع طلاب حقيقيين
هذه **نسخة واجهة أولية للتجربة وليست نظامًا آمنًا متعدد المستخدمين**:
- تبديل المدرس/الطالب في الواجهة للتجربة فقط، وليس صلاحيات فعلية.
- البيانات محفوظة في متصفح الجهاز الحالي فقط، ولا تتزامن بين الأجهزة.
- لا يوجد تسجيل دخول حقيقي أو رفع ملفات سحابي أو تتبع أونلاين فعلي.
- بيانات الطلاب الموجودة بيانات نموذجية، وليست بيانات حقيقية.
- لا تدخل بيانات شخصية أو درجات حقيقية في هذه النسخة.

## الخطوة المجانية التالية
عند الاستعداد، يمكن ربط المشروع بقاعدة بيانات وخدمة تسجيل دخول مثل Supabase Free، مع إعداد صلاحيات وقواعد أمان (RLS) واختبارها قبل استخدام بيانات حقيقية. الاستضافة الثابتة ممكنة عبر GitHub Pages، مع ملاحظة أن GitHub Pages لا يوفر قاعدة بيانات أو تسجيل دخول بحد ذاته.

## نشر مجاني عبر GitHub Pages
1. أنشئ حساب GitHub مجانيًا، وأنشئ مستودعًا جديدًا.
2. ارفع الملفات الثلاثة: `index.html`, `style.css`, `app.js`.
3. من إعدادات المستودع افتح Pages واختر النشر من الفرع الرئيسي والجذر `/`.
4. انتظر رابط النشر. تأكد أن الملفات لا تحتوي على بيانات شخصية.

لا يتم نشر المشروع تلقائيًا من هنا، ولا يتم تعديل مشروع Lovable الحالي بهذه الملفات.
